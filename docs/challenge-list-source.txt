### 17\. Intelligence and autonomy stress tests

These are not about specific software. They test whether S-CLAW actually thinks and adapts.

* Give it an instruction with missing information. It should identify what is missing rather than inventing details.

* Ask it to complete a task using an application it has never used before.

* Give it a task with several possible solutions and let it select the most appropriate.

* Interrupt it halfway through a complex task and ask it to continue.

* Minimize an application while it is working and see whether it can recover.

* Give it two conflicting instructions and see whether it detects the conflict.

* Give it an incorrect file path and see whether it finds the correct location.

* Give it a document containing contradictory information.

* Ask it to perform a task where one application is unavailable.

* Give it a task that requires information from five different files.

* Ask it to identify mistakes in its own work.

* Give it a task that requires multiple rounds of verification.

* Ask it to reproduce a design from a screenshot.

* Give it an existing project and tell it to improve the quality without destroying existing work.

* Ask it to remember a workflow and repeat it with different input data.

* Make an application crash during a task and test recovery.

* Give it a 30-step task and see whether it tracks completed and remaining steps.

* Ask it to compare its final output against the original requirements.

* Give it a task with a deadline and prioritize the essential deliverables.

* Ask it to explain what it did, which files it changed and what remains incomplete.

### My biggest recommendation

Don't give your maker 260 unrelated commands and call that a benchmark.

Create an actual S-CLAW Professional Computer-Use Benchmark with three levels:

* Level 1 – Application Mastery: Can it operate Photoshop, Premiere Pro, Blender, Excel, VS Code and other professional applications?

* Level 2 – Workflow Intelligence: Can it complete complex tasks requiring several applications?

* Level 3 – Autonomous Execution: Can it plan, execute, recover, verify and deliver a complete project with minimal intervention?

The real differentiator is Level 3.

S-CLAW shouldn't merely know how to use Photoshop. It should understand that a customer wants an advertisement, determine what needs to be created, use Photoshop and Premiere Pro appropriately, organize the output and verify the finished campaign.

That's the standard I would challenge your maker to achieve.
